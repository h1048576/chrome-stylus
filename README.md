# 极简样式 SimpleStyle

Stylus 的极简版 Chrome 扩展：只做一件事——给指定网站注入自定义 CSS。

## 界面

三栏布局，比例 **20 : 20 : 60**：

| 左 20% | 中 20% | 右 60% |
|---|---|---|
| 样式列表：点击切换、勾选启用/停用、新建、删除 | 名称 + 生效范围（可添加多条规则） | CSS 编辑器（行号、Tab 缩进、自动保存） |

点击左边的样式，右边内容跟随展示。所有修改自动保存，**页面无需刷新即可实时生效**。

支持**白天 / 夜间模式**切换（左上角 🌙 / ☀️ 按钮）：默认跟随系统偏好，手动切换后会记住选择。三个区域背景统一，白天全白、夜间全黑。

CSS 编辑器带**语法高亮**：注释、选择器、@规则、属性名、数值/颜色、字符串分别着色。注释写法为 `/* ... */`（CSS 标准，不支持 `//`），支持 `Ctrl+/` 快捷注释/取消注释（作用于选中内容，无选中时作用于当前行）。

左上角「禁用 / 启用」按钮可**一键停用或恢复所有样式**；单个样式和单条规则也可用各自的勾选框单独控制。

## 安装

1. 打开 `chrome://extensions`
2. 右上角开启「开发者模式」
3. 点击「加载已解压的扩展程序」，选择本目录
4. 点击工具栏图标（或在扩展详情里点「扩展程序选项」）即可打开管理页

## 生效范围说明

| 类型 | 规则 | 示例 |
|---|---|---|
| 所有 | 任何页面都生效 | |
| URL | 完整地址完全一致 | `https://example.com/a` |
| 前缀 | 地址以此开头 | `https://example.com/blog/` |
| 域名 | 该域名及其所有子域名 | `example.com` |
| 正则 | 对完整地址做正则匹配 | `\.pdf$` |

每条规则前有勾选框，可**单独启用/停用**；停用的规则不参与匹配（规则保留，随时可重新勾选）。

## 文件说明

```
manifest.json   扩展清单（MV3）
background.js   点图标打开管理页
content.js      注入脚本：匹配 URL → 注入 CSS，存储变化时实时更新
manager.html    管理页
manager.css     管理页样式
manager.js      管理页逻辑
icons/          图标（由 icon_gen.py 生成）
```

数据保存在 `chrome.storage.local`，仅存于本机浏览器。

## 与 Stylus 的区别（有意精简）

- 每条样式只有一段 CSS + 一组生效范围，没有多 section / 元数据 / 更新源
- 没有样式市场、导入导出、CSS 语法高亮
- 安装或更新扩展后，已打开的标签页需要刷新一次才会开始注入；之后的样式修改实时生效
